Что такое JSP Action Elements?

Action-элементы JSP — теги, которые выполняются во время запроса и преобразуются контейнером в вызовы методов сервлета. В отличие от директив (<%@ %>), обрабатываемых на этапе трансляции, они управляют потоком выполнения страницы динамически.

В современной разработке JSP используется как шаблонизатор представления (View), но знание action-элементов необходимо для поддержки legacy-проектов.

Подробное описание

Включает содержимое другого ресурса в текущую страницу во время запроса. Контейнер создаёт отдельный запрос к включаемому ресурсу.

<jsp:include page="header.jsp" flush="true" />

Передаёт управление другому ресурсу внутри контейнера. URL в браузере не меняется, выполнение текущей страницы прекращается.

<jsp:forward page="result.jsp" />
Не используйте forward после вывода данных в поток — будет выброшено IllegalStateException.

Элемент для встраивания Java-апплетов. Генерирует тег <object> или <embed>.

<jsp:plugin type="applet" code="MyApplet.class"
            codebase="/applets" width="300" height="200">
    <jsp:fallback>Ваш браузер не поддерживает апплеты.</jsp:fallback>
</jsp:plugin>
Устарел с 2017 года. Апплеты не поддерживаются браузерами. Используйте HTML5, JavaScript или WebAssembly.

История развития

1999 — JSP 1.0

Появились include, forward, useBean.

2001 — JSP 1.2

Добавлен jsp:plugin для апплетов.

2003 — JSP 2.0

Введение Expression Language (EL).

2017 — Отказ от апплетов

jsp:plugin теряет актуальность.

Сегодня — Jakarta EE

JSP → Jakarta Server Pages.

Справка по JSP Actions

Action-элементы выполняются во время запроса и преобразуются в вызовы сервлета.

  • jsp:include — динамическое включение.
  • jsp:forward — перенаправление внутри контейнера.
  • jsp:plugin — устаревший элемент.
Пример
<jsp:include page="header.jsp" />
<%
    if (user == null) {
%>
    <jsp:forward page="login.jsp" />
<%
    }
%>
Шпаргалка
jsp:include
<jsp:include page="файл.jsp" flush="true" />
jsp:forward
<jsp:forward page="файл.jsp" />
jsp:useBean
<jsp:useBean id="user" class="com.example.User" scope="session" />
<jsp:setProperty name="user" property="name" value="Иван" />
<jsp:getProperty name="user" property="name" />
